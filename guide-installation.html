Installation de Spordle Annonceur

Guide pas à pas pour configurer l'extension sur iPad ou iPhone.

Lien direct vers le script

Scannez le code avec l'appareil photo ou touchez directement le bouton ci-dessous dans Safari :

⚡ Télécharger le script (.user.js) Lien court bit.ly →
1

Installer l'application Userscripts

Téléchargez l'application gratuite Userscripts depuis l'App Store. C'est l'extension qui permet à Safari d'exécuter des scripts.

Ouvrir dans l'App Store (apple.co/4hHYsZJ) ↗
Capture d'écran : App Store (Userscripts) assets/guide/step1-appstore.png
2

Activer l'extension dans les Réglages

  1. Ouvrez l'application Réglages de l'iPad.
  2. Allez dans Apps > Safari > Extensions (ou directement Userscripts).
  3. Activez Autoriser l'extension.
  4. Dans la section Autorisations, assurez-vous que les domaines Spordle (play.spordle.com) sont bien configurés sur Autoriser.
Réglages > Extensions > Userscripts : Activer l'extension et vérifier les autorisations d'accès.
3

Vérifier le dossier de travail (Optionnel)

Par défaut, l'application utilise déjà le dossier Userscripts sur votre appareil. Si vous souhaitez le personnaliser ou le vérifier :

  1. Ouvrez l'application Userscripts sur votre écran d'accueil.
  2. Touchez Set Userscripts-Directory.
  3. Confirmez l'accès au dossier Userscripts (ou choisissez un dossier de votre choix).
Capture d'écran : Sélection du dossier dans l'app Userscripts assets/guide/step3-choose-directory.png
4

Télécharger et enregistrer le script

Scannez le code QR ci-dessous avec l'iPad ou ouvrez directement le lien dans Safari :

spordle-annonceur.user.js (Lien direct) →

Touchez le lien ci-dessus ou scannez le code pour lancer le téléchargement.

  1. Au chargement de la page du script dans Safari, touchez la barre en bas : TÉLÉCHARGER.
  2. Dans le menu de partage qui s'affiche, choisissez Enregistrer dans Fichiers.
  3. Sélectionnez le dossier Userscripts (dans Sur mon iPad ou iCloud Drive) et touchez Enregistrer.
⚠️ Important : le fichier doit impérativement se trouver à l'intérieur du dossier Userscripts pour que Safari puisse le charger automatiquement.
1. Toucher « Télécharger » sur le bandeau en bas de la page Safari.
2. Dans le menu de partage, sélectionner « Enregistrer dans Fichiers ».
3. Choisir le dossier « Userscripts » et toucher « Enregistrer ».
5

Vérifier et autoriser sur Spordle

  1. Ouvrez votre feuille de match sur play.spordle.com.
  2. Dans la barre d'adresse de Safari, touchez le bouton Extensions (icône puzzle 🧩 ou aA).
  3. Touchez Userscripts pour vérifier que l'extension est bien active et autorisée sur le site.
  4. Rechargez la page.
🏒 C'est prêt ! Les petites icônes mégaphones 📢 apparaissent désormais à côté de chaque but et punition dans le sommaire. Un toucher dessus affiche le texte officiel complet.
1. Toucher le bouton d'extensions dans Safari puis sélectionner « Userscripts ».
2. S'assurer que le commutateur en haut à droite est activé et que « Spordle Annonceur » est présent dans la liste.
3. Résultat : Les icônes mégaphones 📢 apparaissent sur chaque but et punition du sommaire, et le bouton d'inversion des côtés (⇄) s'affiche à côté de la catégorie.
