Ce script autonome est une copie de test de Spordle Annonceur. Il s'exécute sur Spordle Play et sur notre banc de test officiel hors-ligne.

Téléchargement du script POC (.user.js)

Cliquez sur le bouton vert dans Safari pour télécharger directement le script du POC :

⚡ Télécharger le script POC (.user.js)
💡 Séparation complète : Ce script porte le nom Spordle Annonceur (POC Auto-Update) pour ne jamais entrer en conflit avec votre script officiel.
1
Enregistrez dans Userscripts :
Enregistrez le fichier spordle-annonceur-poc.user.js dans votre dossier Userscripts (ou touchez l'icône Userscripts dans Safari pour le sauvegarder).
2
Testez sur une vraie feuille de match ou le banc de test :
Ouvrez n'importe quel match sur Spordle Play (ou notre banc de test officiel : demo.html).
Vous verrez les vrais boutons mégaphones 📢 ainsi qu'un badge bleu en bas à droite :
📢 Spordle Annonceur POC v1.0.0 [Local]
3
Test de mise à jour autonome :
Dès que vous le voyez actif, confirmez-le-moi : nous déploierons la version v1.0.1 avec un changement de couleur ou un ajout sur le serveur, et vous n'aurez qu'à recharger Spordle pour le voir se mettre à jour tout seul !
