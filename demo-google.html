🧪 Test de Téléchargement & Auto-Update HTTPS

Cette page est hébergée sur GitHub Pages en HTTPS pur pour éliminer tout problème de Mixed Content avec Safari.

Étape 1 : Téléchargement forcé

Cliquez sur le bouton ci-dessous dans Safari sur votre Mac :

⚡ Télécharger le script (.user.js)
💡 Mécanisme actif : fetch() → Blob(application/octet-stream) → URL.createObjectURL. Alternative : appui long → « Télécharger le fichier lié ».
2
Enregistrez le script dans Userscripts :
Enregistrez ou glissez le fichier demo-bg-changer.user.js dans votre dossier Userscripts.
3
Vérifiez sur Google :
Ouvrez google.ca dans Safari. Le fond doit devenir Bleu nuit avec le badge v1.0.0 [Original].
4
Test d'auto-update :
Nous pousserons ensuite v1.0.1 avec le fond Rouge framboise sur GitHub pour observer l'auto-update automatique au simple rechargement !
